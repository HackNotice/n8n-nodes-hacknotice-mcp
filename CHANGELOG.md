#### [v1.0.5](https://github.com/HackNotice/n8n-nodes-hacknotice-mcp/compare/v1.0.4...v1.0.5)

- Re-enable `usableAsTool: true` on HackNotice MCP Client with a single stable schema (operation + toolName + toolArguments). The AI Agent now sees exactly one tool; internal routing decides which MCP method to call. Sidesteps the OpenAI "must be a JSON Schema of type object" errors that the built-in MCP Client Tool produced when enumerating 50+ heterogeneous tools individually.
- Update node description and remove the canvas notice that pointed users to the built-in MCP Client Tool.
- Switch `Arguments (JSON)` field to `type: json` for a better editor experience on the canvas and a clean object schema in AI-tool mode.

#### [v1.0.4](https://github.com/HackNotice/n8n-nodes-hacknotice-mcp/compare/v1.0.3...v1.0.4)
