#### [v1.0.4](https://github.com/HackNotice/n8n-nodes-hacknotice-mcp/compare/v1.0.3...v1.0.4)

- Refactor **HackNotice MCP** into a dedicated AI Agent tool node (`supplyData` + `DynamicStructuredTool`) wired to the AI Agent **Tool** input.
- Discover tools live from the HackNotice MCP server via `tools/list`, with a 5-minute per-integration-key catalogue cache to avoid repeated HTTP calls on every LLM iteration.
- Add **Tools to Expose** filtering: expose all tools, only selected tools, or all except selected tools.
- Show human-readable MCP `title` labels and tool descriptions in the **Tools to Include** / **Tools to Exclude** dropdowns instead of technical tool names.
- Add **Debug Mode** to force `debug: true` on every MCP tool call and surface redacted `_debug` traces in responses.
- Add `execute()` support required by n8n's v3 AI Agent engine so tool invocations are recorded in executions.
- Add `zodHelpers` to convert MCP `inputSchema` JSON Schema into Zod objects for LangChain tool schemas.
- Normalize common LLM argument aliases (for example `query` → `term`) before MCP `tools/call`.
- Update README for AI Agent usage, tool filtering, debug mode, and prompting tips.
